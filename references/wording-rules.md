# 措辞规则：动词、数字、风险、请求

## 一、动词替换表

| 流水账动词（删） | 换成 |
| --- | --- |
| 跟进、推进、对接、沟通 | 促成 {结论} / 对齐 {分工} / 定了 {时间点} |
| 负责、参与、配合 | 主导 {产出} / 承担 {模块} / 支撑 {结果} |
| 优化、提升、改善 | 把 {A} 从 {X} 改到 {Y} |
| 帮忙、协助 | 交付 {具体产物} |
| 学习、了解 | 落地 {一件事}（学习本身不是成果） |

**规则**：动词后面必须能接一个**名词性的产物**（方案、名单、机制、版本、报告）。接不上的，就是过程词。

## 二、找数字：五类可量化维度

| 维度 | 没有精确数时怎么估 | 写法 |
| --- | --- | --- |
| 规模 | 涉及多少人/客户/单量/系统 | 覆盖 340 家客户、12 个业务线 |
| 比例 | 抽样估算、历史对比 | 转化率 3.1% → 4.6% |
| 时长 | 前后对比、人工估算 | 周期 18 天 → 6 天 |
| 金额 | 单价 × 数量、人力成本折算 | 年省 42 万、多留 340 万 |
| 频次 | 日/周次数 × 周期 | 每周 3 次，月省 9 小时 |

**口径必须写**：`转化率 4.6%（注册完成 / 进入注册页，剔除重复提交）`。
**估算要标**：写「约」「按 X 折算」，不要写成一模一样的精确数。

## 三、风险怎么报（四段式）

```
{风险事实} → {对目标的影响，带数字} → {我的方案与代价} → {需要你决定什么，最晚何时}
```

例：
> 供应商 A 的物料排期延后 5 天（事实）→ 11/3 上线会推迟到 11/8，影响首周预估 GMV 约 12 万（影响）→ 我有两个方案：换供应商 B 加价 8% 保 11/3，或维持 A 推迟 5 天（方案与代价）→ 我建议换 B，因为首周是活动窗口。需要你今天下班前确认（请求与时限）。

**三种错误报法**：
- 只报事实不报影响：「供应商延期了」——领导无法判断严重性。
- 报影响不给方案：「可能要推迟」——把决策成本丢给领导。
- 给方案不问时限：「你看怎么办」——事情会烂在原地。

## 四、要支持怎么说（不显得无能）

| 弱 | 强 |
| --- | --- |
| 「人手不够」 | 「要按期交付，还需要 1 名前端 2 周；没有的话我建议砍掉导出功能」 |
| 「需要领导支持」 | 「需要你在周三的会上明确优先级：A 优先于 B」 |
| 「资源协调不了」 | 「A 团队本周排满了，需要你跟他们负责人对一次」 |

**公式**：`具体资源 + 用途 + 时长 + 没有时的备选方案`。给备选方案，是让领导只需选、不用想。

## 五、语气与场合

| 对象 | 语气 | 注意 |
| --- | --- | --- |
| 直属上级 | 直给结论，细节放手边 | 他要的是判断依据，不是过程 |
| 跨级/高管 | 更短，一屏，只留决策项 | 不要出现只有你懂的缩写 |
| 客户 | 先说对他们意味着什么 | 少用内部术语，多给时间点 |
| 全员 | 讲意义与进展 | 不写具体人名问题，不写内部矛盾 |
